# MarkFlow 快捷键手册

> Cmd = macOS ⌘；Windows / Linux 上对应 Ctrl。**加粗**为当前已实现并验证的快捷键。

## 文字格式（行内）

| 功能       | macOS               | Windows / Linux            | 状态  |
| -------- | ------------------- | -------------------------- | --- |
| **加粗**   | **Cmd+B**           | **Ctrl+B**                 | ✅   |
| **斜体**   | **Cmd+I**           | **Ctrl+I**                 | ✅   |
| **行内代码** | **Ctrl+\` 或 Cmd+E** | **Ctrl+Shift+\` 或 Ctrl+E** | ✅   |
| **删除线**  | **Cmd+Shift+S**     | **Ctrl+Shift+S**           | ✅   |
| 下划线      | Cmd+U               | Ctrl+U                     | 待实现 |
| 高亮       | —                   | —                          | 待实现 |
| 超链接      | Cmd+K               | Ctrl+K                     | 待实现 |
| 图片       | Cmd+Ctrl+I          | Ctrl+Shift+I               | 待实现 |
| 清除格式     | Cmd+\\              | Ctrl+\\                    | 待实现 |

**智能格式语义**（加粗 / 斜体 / 行内代码 / 删除线通用，Typora 同款）：

- 选中文字 → 只切换选区；
- **不选中**，光标在普通文本里 → 以**空格为界**给当前词加格式（如「对于 token 而言」光标在 token 内按 Cmd+B 只加粗 token；整行无空格时即整行）；
- **不选中**，光标在格式文字里 → 再按一次取消整段连续格式（不用先全选）。

## 段落与块级（Typora 风格）

| 功能             | macOS              | Windows / Linux                 | 状态               |
| -------------- | ------------------ | ------------------------------- | ---------------- |
| **段落（正文）**     | **Cmd+0**          | **Ctrl+0**                      | ✅                |
| **一级 \~ 六级标题** | **Cmd+1 \~ Cmd+6** | **Ctrl+1 \~ Ctrl+6**            | ✅                |
| **标题升级 / 降级**  | **Cmd+= / Cmd+-**  | **Ctrl+= / Ctrl+-**             | ✅                |
| **标题行行首退格**    | **Backspace**      | **Backspace**                   | ✅（标题直接转正文段落） |
| **代码块**        | **Cmd+Option+K**   | **Ctrl+Shift+K**                | ✅                |
| **公式块**        | **Cmd+Shift+M**    | **Ctrl+Shift+M**                | ✅                |
| **引用**         | **Cmd+Shift+Q**    | **Ctrl+Shift+Q**                | ✅                |
| **无序列表**       | **Cmd+Option+]**   | **Ctrl+Shift+] 或 Ctrl+Alt+]**   | ✅                |
| **有序列表**       | **Cmd+Option+\[**  | **Ctrl+Shift+\[ 或 Ctrl+Alt+\[** | ✅                |
| **任务列表**       | **Cmd+Option+9**   | **Ctrl+Alt+9**                  | ✅                |
| 表格             | Cmd+T              | Ctrl+T                          | 待实现（浏览器保留键，需改键位） |
| 水平分隔线          | Cmd+Shift+-        | Ctrl+Shift+-                    | 待实现              |

**块首退格的另外两个行为**：光标在块首按 Backspace——上方是水平分隔线时一步删除（不用先选中再删）；代码块 / 公式块内再按对应快捷键（Cmd+Option+K / Cmd+Shift+M）可直接转回正文段落。

## 平台差异说明

1. **Cmd+Shift+` 在多数 mac 键盘 / 输入法下按不出**（Typora 同款问题），行内代码请用 **Ctrl+`** 或 **Cmd+E**。
2. **Cmd+Shift+] / \[ 是 Chrome 切换标签页的保留键**，mac 上列表请用 **Cmd+Option+] / \[**；Windows 的 Ctrl+Shift+] / \[ 不冲突，两组都可用。
3. **Cmd+T（表格）、Cmd+/（源码模式）** 被浏览器占用，网页无法拦截，未来会改用 Option 组合的键位实现。
4. 光标进入表格时表格上方会自动出现工具栏（对齐、行列增删、源码、删除），无需快捷键。
5. **编辑区缩放只作用于正文**（topbar / 侧栏尺寸恒定），范围 60%–200%，设置自动记忆。

## 输入法快捷语法（无需快捷键）

* `code` 行内代码、`$$公式$$`、\`\`\` 代码块（输入后回车）
* `#` + 空格 标题、`>` + 空格引用、`-` + 空格列表、`- [ ]` + 空格任务列表
* `|a|b|` 回车建表格、`---` 回车分隔线

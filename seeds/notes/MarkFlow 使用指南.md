# MarkFlow 使用指南

## 常用操作

### 文件管理

- 左侧边栏顶部 **新建文件 / 新建文件夹**
- 文件/文件夹右侧 **`⋯` 菜单**：重命名、移动、删除
- 所有改动保存在服务器数据库中，没有"回收站"，删除前请确认

### Typora 主题

1. 把 `.css` 主题文件放进服务器主题目录（Docker 部署时即挂载的 `themes/` 卷）
2. 刷新页面后，右上角主题选择器里就会出现新主题
3. 主题同时作用于编辑器与 PDF 导出

### PDF 导出

点击顶栏 **导出 PDF**：服务端用无头浏览器按当前主题渲染，包含页眉（文档名）与页脚（页码），稍等数秒自动下载。

### 外部编辑

直接在服务器上 `vim`、`git pull` 修改 `.md` 文件——在线页面会自动同步，无需刷新。为避免覆盖，外部改动后请不要在旧内容未同步前立刻保存。

## 快捷键

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl/Cmd + B` | 加粗 |
| `Ctrl/Cmd + I` | 斜体 |
| `Ctrl/Cmd + K` | 行内代码 |
| `Tab` / `Shift+Tab` | 缩进/反缩进列表 |
